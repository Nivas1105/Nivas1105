## How I Think About Projects

```text
Question → Data contract → Pipeline → Model / analysis → Validation → Useful outcome
```

- **Start with the decision.** A technically impressive result is still a miss if nobody can use it.
- **Make the data trustworthy.** Reproducibility, quality checks, and observable pipelines are part of the work.
- **Prefer clarity over ceremony.** The best solution is usually the one another engineer can understand and operate.
